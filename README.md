## 內容涵蓋
- **Version 1–3.2026 重點更新**：PV 新增 Rusfertide (Cat 1)、ET 二線 Ropeginterferon alfa-2b-njft (Cat 1)、MF 貧血 Momelotinib (Cat 1)、移植後 MRD 監測、JAKi / IFN / Anagrelide 安全須知
- **診斷與風險分層**：MPN-1 Workup、WHO 2022 / ICC 診斷標準 (PMF / PV / ET / Post-PV MF / Post-ET MF)、骨髓纖維化 MF-0~3 分級、驅動與 HMR 突變預後
- **分病治療流程**：低/高風險 MF、MF 相關貧血、Allo-HCT 考量、低/高風險 PV、各風險層級 ET、Hydroxyurea 抗藥與不耐受定義、加速期/芽細胞期 MPN
- **整合照護與互動計算機**：症狀處置、血栓/出血/手術/懷孕管理，內建 DIPSS / DIPSS-Plus / MIPSS-70+ v2.0 / MYSEC-PM / Revised IPSET-thrombosis / MIPSS-PV / MIPSS-ET 與 MPN-SAF TSS (MPN-10) 計算機。
